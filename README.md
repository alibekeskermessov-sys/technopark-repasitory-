# Деплой на Netlify

Один файл **`index.html`** — весь сайт (меню, одиночная игра, игра с другом по коду).

## Как залить

1. Зайдите на [app.netlify.com](https://app.netlify.com)
2. **Add new site → Deploy manually** (или перетащите папку `netlify` в окно)
3. Либо подключите Git и укажите:
   - **Base directory:** `netlify`
   - **Publish directory:** `.` (или `netlify`)

После деплоя откройте выданный URL (обязательно **https** — для игры с другом нужен защищённый протокол).

## Режимы

| Режим | Как играть |
|--------|------------|
| **Одиночный** | Сразу матч против компьютера |
| **С другом** | Один создаёт комнату и сообщает **код**, второй вводит код на другом устройстве → игра стартует сама |

Победа: опередить соперника на **50** кликов.

## Сеть (режим «С другом»)

Используется [PeerJS](https://peerjs.com) (бесплатный сигнальный сервер). Интернет нужен обоим игрокам. Если не подключается — обновите страницу и создайте новую комнату.

## Локальная проверка

```bash
cd netlify
python3 -m http.server 8080
```

Откройте `http://localhost:8080` (для PeerJS лучше тестировать уже на Netlify по HTTPS).
